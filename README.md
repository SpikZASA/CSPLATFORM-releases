# CS Platform: downloads

A side-view, Counter-Strike-style game for Windows, made with Godot. Plant or defuse the bomb, buy guns, fight bots, or play online with friends.

**[Download the latest version](https://github.com/SpikZASA/CSPLATFORM-releases/releases/latest/download/CSPlatform.zip)** (or see all versions under [Releases](https://github.com/SpikZASA/CSPLATFORM-releases/releases)).

## Run it

1. Unzip `CSPlatform.zip` anywhere.
2. Double-click `CSPlatform.exe`. Nothing to install.
3. Windows may say "Windows protected your PC" because the game is not signed: click "More info", then "Run anyway".

You need Windows 10 or 11 (64 bit) and a graphics card with Vulkan support (nearly every PC of the last ten years). The zip also has `HOW TO PLAY.txt` with the controls.

## Play online

Main menu, then Multiplayer, then type the address of the server (ask whoever hosts it). You and the server must run the same version: if the game says the server runs another version of the game, download the latest release from this page.

## About

All art and sound in the game is free to use (CC0); the credits are in `CREDITS.txt` inside the zip. This repository only holds the downloads; the game itself is developed elsewhere.
